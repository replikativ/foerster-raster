# spindel-raster

Raster-compiled numerical blocks inside [spindel](https://github.com/replikativ/spindel)
probabilistic programs: log densities and their derivatives from
[raster](https://github.com/replikativ/raster), with addresses, traces,
proposals and acceptance owned by spindel.

Early work. The contract between the two sides is [doc/contract.md](doc/contract.md).
